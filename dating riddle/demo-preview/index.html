Database Storage Architecture

Icebreaker AI uses an embedded SQLite 3 engine located at backend/app/data/icebreaker.db. Every generated opener, reply coach suggestion, rescue strategy, and Riddle 2 decode is committed with structured timestamps, respect safety scores, and request parameters. When SUPABASE_URL is configured, updates are asynchronously broadcast to the cloud for multi-device sync.

Local Reliability: Zero database setup required. Runs instantly on any laptop or server without spinning up external containers.
Safety & Audit Trail: Maintains respect and non-manipulation scores to evaluate model output quality over time.
Table: conversations PRIMARY KEY (id)
id TEXT PRIMARY KEY
tool_type TEXT (icebreaker | reply_coach | rescue | rewrite | what_was_meant)
channel TEXT (setting or context category)
input_payload JSON TEXT
output_payload JSON TEXT
respect_score INTEGER (0-100)
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
Table: riddle_decodes PRIMARY KEY (id)
id TEXT PRIMARY KEY
ambiguous_phrase TEXT ("Fine.", "Maybe", delay)
gap_risk_score INTEGER (0-100%)
diagnosis TEXT
selected_bridge TEXT
created_at TIMESTAMP
Table: saved_favorites PRIMARY KEY (id)
id TEXT PRIMARY KEY
tool_type TEXT
text_content TEXT
tag TEXT
created_at TIMESTAMP
